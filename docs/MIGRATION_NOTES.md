# Consolidation notes

This repository is a single cleaned implementation, not a collection of the
historical week-numbered scripts. During consolidation, two code-level issues
were found that affect which existing result files can be regenerated by the
unified code.

## Vertical Wavelet parameter selection

The selected random-mask Wavelet results used the 20-point lambda sweep and
automatic L-curve selection. The available historical vertical-mask Wavelet
results used an earlier fixed-threshold implementation. The unified repository
uses the automatic L-curve implementation for both masks. Therefore, a new
vertical Wavelet run is required before claiming that its rows were generated by
this repository.

## L1 cutoff calibration level

The historical L1 cutoff-sweep scripts passed `L=4` to the dictionary builder,
while the subsequent L1 Monte Carlo scripts correctly passed `L=1`. The stored
L1 cutoff tables confirm the former behavior through their atom counts. The
unified calibration code uses the requested level consistently, so an L1 cutoff
calibration and the dependent L1 Monte Carlo jobs should be regenerated for both
mask types.

These are targeted reruns rather than a reason to rerun the complete study. The
current Linear, Wavelet-random, Shearlet, and Boostlet L2--L4 implementations are
represented by the consolidated modules and configuration.
