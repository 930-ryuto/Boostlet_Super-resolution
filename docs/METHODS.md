# Numerical methods

## Data preprocessing

The input is the line-array room impulse response stored under
`/line02/impulse_response`. Receiver order is reversed to match the original
spatial convention. The temporal sampling rate is changed from 48 kHz to

```text
f_target = c / dx,
```

where `c = 343 m/s` and `dx` is obtained from `/line02/posRIR`. Polyphase
resampling uses the rational approximation produced by
`Fraction(f_target / 48000).limit_denominator(1_000_000)`. Each experiment uses a
128-by-128 time-space window.

Early windows start in `[600, 2315]`; late windows start in `[2316, 19894]`.
Spatial starts lie in `[1, 73]`. All indices are 1-based in configuration and
CSV output.

## Sampling and noise

For a random mask, `round(rho * Nt * Nx)` individual samples are retained. For a
vertical mask, `round(rho * Nx)` receiver columns are retained in full. The mask
of trial `i` is generated by NumPy's legacy `RandomState(i)`, where the internal
trial index starts at zero.

Additive white Gaussian noise is scaled from each clean window's mean-square
power to the requested input SNR. The same standard-normal realization is reused
across methods within a paired condition.

## Linear baseline

The observed zero-filled field is transformed with a centered two-dimensional
FFT. Frequencies outside the far-field cone

```text
|kx| < 0.95 |omega|
```

are removed, followed by an inverse FFT. The method has no iterative parameter.

## Wavelet baseline

The wavelet operator is a two-level `db38` two-dimensional decomposition with
periodization boundary handling. Reconstruction uses the common FISTA solver and
L-curve parameter selection.

## Shearlet baseline

The Shearlet operator uses pyShearLab with two scales and the normalized `cd`
directional filter. Coefficient indices `[2, 5, 6, 7, 8, 9]` are zeroed in every
FISTA iteration.

## Boostlet L1--L4

The discrete Boostlet dictionary partitions the normalized `(k, omega)` plane
using Meyer radial windows and rapidity windows in near- and far-field cones. A
top-frequency residual cap is included. L1--L4 use the same construction with a
different number of radial scales.

Each L is a fixed method. The following artifact indices are removed:

| Level | Fixed indices |
|---|---|
| L1 | 5--9 |
| L2 | 5--9, 18--20 |
| L3 | 5--9, 18--20, 28--30 |
| L4 | 5--9, 18--20, 28--30, 37 |

An adaptive high-frequency cutoff is calibrated separately for every mask type,
level, sampling ratio, and input SNR. At each calibration `T_start`, the cutoff
with minimum oracle RRMSE is retained. A Monte Carlo window uses the retained
cutoff from the closest calibration `T_start`. Atoms whose peak normalized
frequency exceeds that cutoff are suppressed in addition to the fixed indices.

## FISTA and lambda selection

Sparse methods use a FISTA step size of 1.0 and 200 iterations. For lambda factor
`a`, the threshold is

```text
a * MAD(y_observed) * sqrt(2 log(N)).
```

Twenty factors logarithmically span `1e-4` to `1`. The automatic factor is the
corner selected from smoothed residual/solution L-curves. Oracle RRMSE and its
factor are saved for diagnostics only; the primary reported result is automatic
RRMSE.

## Metrics

- RRMSE: `100 * ||x - x_hat||_2 / ||x||_2`
- PSNR: scikit-image PSNR with `data_range=1`
- SSIM: scikit-image SSIM with `data_range=1`
- Output SNR: `10 log10(var(x_hat) / var(x - x_hat))`

## Statistical analysis

Rows are paired by mask, timing, sampling ratio, input SNR, trial ID, and window
coordinates. Each non-Shearlet method is compared with Shearlet using the paired
difference in automatic RRMSE. The output reports the mean difference, Student-t
95% confidence interval, paired t statistic, raw p-value, within-condition Holm
adjustment, global Holm adjustment, and fraction of trials with a negative
difference. Negative differences favor the comparison method.

Method rankings use condition-level mean RRMSE. The condition-wise best Boostlet
level is produced only as an explicitly exploratory table; it is not substituted
for the fixed L1--L4 series in the primary figures.
